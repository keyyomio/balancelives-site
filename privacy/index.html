개인정보처리방침 (국문)

발란스리브즈(BALANCELIVES)는 이 웹사이트(balancelives.site)와 이 사이트에 표시된 연락처를 통한 문의에 대해 다음과 같이 안내합니다. 이 방침의 범위는 본 스튜디오 웹사이트입니다.

1. 웹사이트에서 처리하는 정보

이 사이트에는 회원가입, 결제, 문의 폼, 광고, 방문 분석 도구가 없습니다. 자체적으로 쿠키를 설정하거나 방문자 정보를 브라우저 저장소에 보관하지 않습니다. 이메일 복사 버튼은 사용자가 누를 때에만 공개된 연락 이메일을 클립보드에 씁니다.

2. 이메일·전화 문의

문의 시 제공하신 이메일 주소, 전화번호, 이름(제공한 경우), 문의 내용은 문의 확인과 답변을 위해 처리합니다. 민감정보나 불필요한 개인정보는 보내지 말아 주세요. 문의 기록은 답변 및 후속 대응에 필요한 동안 보관한 뒤 삭제하며, 법령에 따른 보관 의무가 있는 경우 해당 기간을 따릅니다.

3. 호스팅과 외부 서비스

이 사이트는 GitHub Pages로 제공됩니다. GitHub는 보안 및 서비스 제공을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요. 이메일·전화 링크를 선택하면 이용자의 메일 또는 전화 서비스가 열립니다.

4. 정보 제공과 권리 행사

문의 내용을 판매하거나 광고 목적으로 이용하지 않습니다. 법령에 따른 경우를 제외하고 문의 내용을 임의로 외부에 제공하지 않습니다. 본인 정보의 열람, 정정, 삭제, 처리 정지에 관한 요청은 아래 연락처로 보내 주세요. 본인 확인 후 관련 법령에 따라 처리하고 결과를 안내합니다.
